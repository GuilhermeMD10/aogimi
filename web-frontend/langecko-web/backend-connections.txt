7. SYNC & PERSISTENCE PATTERNS
==============================================================================

Book progress sync (reader page):
  - Local: immediate save to localStorage on every page turn
  - Backend: first sync immediate, subsequent syncs debounced 2s
  - Failures silently ignored (non-critical)

Library sync (library page mount):
  1. Load local books from IndexedDB
  2. Register any missing books to backend via POST /api/books
  3. Fetch all backend records via GET /api/books/user/{id}
  4. Merge and display

Profile page load:
  - Fetches user info, books, and decks in parallel via Promise.allSettled()
  - Each can fail independently without blocking the others

Client-side storage:
  - localStorage: auth_user, reader_progress_{filename}, lgc_avatar_index,
                   dictionary_state, app-theme
  - IndexedDB (langeco-books): metadata store, files store (EPUB/PDF blobs)
